# Night Blue implementation plan

**Status: completed for v0.1. See the [current architecture](../architecture/overview.md) for the five-variant package.**

Ship a local-testable, packable `tomorrow-night-blue` in the `pi-tomorrow-theme`
package. Use [the architecture](../architecture/overview.md) for color ownership
and runtime boundaries. More variants, a terminal profile installer, a
Markdown extension, publishing to npm, and changing a user's Pi defaults are
out of scope.

| Slice | Work | Acceptance |
| --- | --- | --- |
| 1. Theme | Add the full Pi 1.5.2 JSON. Preserve the upstream core palette, map Pi panels and Markdown distinctly, and keep the original comment color separate from readable UI text. | No missing Pi color roles or unresolved palette references. Common body and secondary text pairs meet 4.5:1 on the intended surfaces. |
| 2. Package | Declare the theme only in `package.json`, add the original MIT notice and a README with local preview and background guidance. | `npm pack --dry-run` lists the theme, manifest, README, and license with no executable entry point or install script. |
| 3. Runtime preview | Render the synthetic session in Pi 1.5.2 with `dark` and `tomorrow-night-blue`, using a pseudo-terminal and throwaway settings. Do not submit a prompt. | Both runs show the same sample text. The Night Blue run emits its distinct heading, inline code, user/tool backgrounds, and diff accents. |

The preview covers headings, inline and fenced code, quotation, links, completed
and failed tools, and a diff. Truecolor and a matching terminal backdrop are the
reference appearance; different palettes or NO_COLOR can change perceived
contrast. Local use via `--theme` and `--use-theme` is temporary: exit Pi to
revert and delete any scratch session copy.

## Verification in this checkout

- `python3 test/check.py` checks 20 foreground/background pairs, then replays
  the fixture in both themes under an isolated Linux PTY. Both runs showed the
  sample text; eight Night Blue styles were observed in Pi's ANSI output.
- Syntax comments retain the original `#7285b7`. That color measures 4.20:1
  on `#002451`; it is intentionally less prominent than ordinary UI text.
- `npm pack --dry-run --ignore-scripts` verifies the package includes the theme,
  manifest, documentation, and license but excludes the test suite.
- The PTY check verifies emitted text and colors. Review the actual appearance
  on a matching terminal background using the README's preview command.
